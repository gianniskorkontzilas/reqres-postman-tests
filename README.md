# ReqRes API – Postman Tests

## 📌 Project Overview
This project contains automated API tests for the public API:
https://reqres.in/

The tests were created using Postman and validate different API endpoints.

---

## 🛠 Tools Used
- Postman
- GitHub
- ReqRes API

---

## 📂 Project Structure
- `reqres-tests.postman_collection.json` → Postman collection with all requests and tests
- `reqres-environment.json` → Environment variables 

---

## ✅ Test Cases Included

The collection includes tests such as:

- Status code validation (200, 201, 404 etc.)
- Response time is less than 200ms
- Correct page name validation
- Correct number of entries per page
- Response body validation
- JSON structure validation

---

## ▶️ How to Run the Tests

1. Download the collection JSON file
2. Open Postman
3. Click **Import**
4. Select the collection file
5. Run the collection using the Collection Runner
